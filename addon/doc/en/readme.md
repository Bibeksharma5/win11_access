# Accessibility Enhancement for Windows 11 (win11_access)

* **Author:** Bibek Sharma Dhakal
* **Version:** 1.0
* **NVDA Compatibility:** 2026.1 to 2026.3
* **Target OS:** Windows 11
* **Homepage:** [https://github.com/Bibeksharma5/win11_access](https://github.com/Bibeksharma5/win11_access)

This add-on provides lightweight but important accessibility enhancements for Windows 11, inspired by [Windows App Essentials](https://github.com/josephsl/wintenApps).

---

## Features

* **Windows Search (Start Menu):** Suppresses repetitive `"context menu list"` announcements when navigating search result context menu items with Up/Down arrow keys.
* **Windows Settings (Installed Apps):**
  * Announces the total number of applications found when focusing the "Filter by drive" combo box.
  * Automatically announces each application's storage size while navigating through the installed applications list.
* **Windows Calculator:** Automatically announces the active calculation mode (e.g. Standard, Scientific, Programmer) upon opening Calculator.

---

## Installation

1. Download or locate `win11_access.nvda-addon`.
2. Press `Enter` on the file or install it through NVDA Menu > **Tools** > **Add-on Store**.
3. Confirm the installation prompt and restart NVDA.
